# Clinical Trial Finder

**Live app:** https://clinicaltrialfinder.streamlit.app/

**Watch the Clinical Trial Finder walkthrough on Loom** https://www.loom.com/share/22e05e5979de4a90965de57b4af893cd

Clinical Trial Finder searches ClinicalTrials.gov for trials that are currently recruiting or not yet recruiting, for a medical condition in a chosen country. Each trial has an AI-generated plain-English summary of its brief summary, written on request with Google Gemini.

## Medical disclaimer

This page uses AI to rewrite simple trial descriptions. It is not medical advice and does not check your eligibility to participate in any clinical trial. Talk to your doctor before you decide anything about participating in a clinical trial.

## Ethics and responsible use

**Permission to use the data.** This app uses the public ClinicalTrials.gov API (version 2), which the registry makes available for public use under its terms. The app makes one request per search and keeps search results only temporarily, rather than downloading or republishing the registry. It attributes the source, shows the dates involved, and lists its modifications, as the terms require. Anyone who reuses this code or its data should follow the same terms.

**Limits of what this app shows.** Please keep these limits in mind when you search:

- The list is not complete. It shows only trials that are recruiting or not yet recruiting, that are registered on ClinicalTrials.gov, and that match your condition and country. Trials registered elsewhere, or not yet registered, are not shown.
- Records can be out of date. ClinicalTrials.gov records are updated by their sponsors, so a trial may have closed, changed, or filled since its record was last updated.
- AI summaries can be wrong or leave things out. They are rewrites of the registry text, not the official description. Check the full record on ClinicalTrials.gov before you rely on any summary.
- Being listed does not mean you are eligible. Only the trial team can decide that, so contact them through the registry record.

**Taking care with people who are searching.** Searching for a trial often comes from someone who is seriously ill and looking for hope. Clinical trials can help some people, but they carry risks, and many people who search will not be eligible or will not benefit. The app therefore tells users to talk to their doctor before they decide anything, and it does not present any trial as a recommendation.

**Privacy.** The app does not ask for personal or health information, and it does not store individual searches. The hosting platform may keep standard access logs that record when the app is used.

## How this app changes the registry data

- Plain-English summaries are AI-generated rewrites of each study's brief summary. They are shown in place of the brief summary and are labelled as AI-generated.
- Only studies with the status Recruiting or Not yet recruiting are shown, in two groups.
- Only these fields are shown: title, status, conditions, interventions, phase, primary outcome, and the AI summary.
- Eligibility criteria and contacts are not shown. Each trial links to its record on ClinicalTrials.gov.
- Studies are matched to the condition you enter, and studies with no listed site in the chosen country are excluded.

## Run locally

1. Clone the repository and open the folder.
2. Create a virtual environment and install the requirements:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Create a file named `.env` in the project folder with your Gemini API key:
   ```
   GEMINI_API_KEY=your-key-here
   ```
4. Start the app:
   ```
   streamlit run app.py
   ```

Summaries are cached in `cache/live_summaries.json`, so each summary is generated only once.
